# Guru Krupa Mandap Decoration Website

## Files
- index.html
- style.css
- script.js
- images/  (apni photos yaha rakho)

## VS Code me kaise chalana hai
1. Folder ko VS Code me open karo.
2. index.html open karo.
3. Browser me Open with Live Server karo.
4. script.js me `whatsappNumber` ko apne number se replace karo.
   Example: `919876543210`
5. Hero image ke liye `images/hero.jpg` naam ki photo rakho.

## Project Features
- Home
- Services
- Decoration Gallery
- Online Booking
- Offline Booking option
- WhatsApp booking
- Contact details
- Responsive mobile design
